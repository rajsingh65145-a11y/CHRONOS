## 🌌 Project Vision & Features

**CHRONOS** ek high-end cinematic web application hai jo users ko alag-alag epochs ke beech temporal journey karwati hai:
- 🌋 **01 // Ancient Earth (65,000,000 BCE):** Primordial volcanic fire, solar eclipse corona, and levitating basalt monoliths.
- 🏙️ **02 // Present Day (2026 CE):** Hyper-connected anthropocene, orbital telemetry rings, and quantum spires.
- 🚀 **03 // Future 3026 (3026 CE):** Post-planetary Dyson harvesting rings, synthetic plasma, and zero-G citadels.

### Key Technical Highlights:
- **Cinematic Opening Portal Gate:** 3D gyroscopic rotating rings, relativistic plasma accretion disks, and smooth hyper-jump transitions.
- **Dynamic Era Theming:** CSS variables (`:root` and `[data-era="..."]`) jo real-time mein color palette aur typography (`Cinzel`, `Space Grotesk`, `Orbitron`) switch karte hain.
- **60fps Desktop-Optimized Parallax & Scroll Engine:** Hardware-accelerated transforms (`translate3d`), scroll progress laser bar, and `IntersectionObserver` reveal blocks.
- **Accessibility & Eco-GPU Mode:** Manual reduced-motion toggle, WCAG skip links, screen-reader announcements (`aria-live`), and global keyboard shortcuts (`1`, `2`, `3`, `Arrow Keys`, `Esc`).

## 🛠️ Tech Stack
- **Framework:** React 18+ (Vite Bundler)
- **Styling:** Standard CSS3 (Modular architecture, zero Tailwind, zero Bootstrap, zero unnecessary dependencies)
- **Typography:** Google Fonts (`Cinzel`, `Orbitron`, `Space Grotesk`, `JetBrains Mono`)

## 🚀 Getting Started Locally

Apne local machine par project run karne ke liye ye steps follow karein:

```bash

git clone [https://github.com/your-username/chronos.git](https://github.com/your-username/chronos.git)

# 2. Navigate to project directory
cd chronos

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
