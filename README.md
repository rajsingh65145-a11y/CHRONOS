## 🌌 The Concept

What if you could travel through time without leaving your screen?

**CHRONOS** is a cinematic frontend experience inspired by the mysteries of time travel, futuristic technology, and immersive digital storytelling.

Step through a glowing temporal portal and explore three distinct timelines, each with its own atmosphere, visual identity, and story.

From the forgotten landscapes of ancient Earth to the world we live in today, and finally to a civilization a thousand years into the future — every era offers a different perspective on time.

This is more than a website. It's an experiment in making the browser feel like another dimension.

## 🚀 The Experience

### 🏛️ 01 — Ancient Earth

Travel into a world shaped by ancient civilizations, mysterious landscapes, and the origins of human history.

### 🌍 02 — Present Day

Return to the world we know — a constantly evolving reality caught between history and the future.

### 🛸 03 — Future 3026

Enter a distant future of advanced civilizations, futuristic architecture, and technology that pushes the limits of imagination.

*Each timeline is designed to deliver its own atmosphere and visual experience.*

## ✨ Key Features

* **Cinematic Time Portal** — A visually striking portal that introduces the time-travel experience.

## ⚡ Getting Started

Run CHRONOS locally on your machine.

### Prerequisites

* [Node.js](https://nodejs.org/) — Install a current compatible version.
* npm — Included with Node.js.
* Git — Optional, if cloning the repository.

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate into the project**

```bash
cd chronos
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Vite will display a local development URL in the terminal, usually:

```text
http://localhost:5173
```

> Replace `YOUR_REPOSITORY_URL` with your actual Git repository URL. If your project folder has a different name, update the `cd` command accordingly.
